# 程序化 SEO (Programmatic SEO) 实战操作手册

程序化 SEO 是出海工具站突破流量天花板的杀手锏。通过结构化数据组合批量生成能解决用户长尾特定需求的页面。

## 一、 核心数学模型与场景选择

1. **二维矩阵参数模型**: `/[tool-name]/[parameter-a]-to-[parameter-b]`
   - 示例：`convert/[from_format]-to-[to_format]` （如 heic-to-jpg, psd-to-png）
   - 示例：`resize/[platform]-[purpose]` （如 instagram-story, youtube-thumbnail）
2. **适用判定标准**:
   - 用户具备明确的“长尾特定词”检索行为。
   - 每个参数组合都有真实明确的技术解或数据解。
   - 页面能为用户节省配置参数的时间（预设化输入）。

## 二、 拒绝 Thin Content：独特性防御 5 要素

严禁仅替换标题中的两个词而内容一成不变！Google 的 Helpful Content System 会严打空壳模版。每个落地页必须满足以下独特性检查：

1. **动态交互默认值**: 当用户访问 `/convert/heic-to-jpg` 时，工具默认目标导出格式自动锁定为 `JPG`，上传控件直接接受 `.heic` 格式。
2. **针对性技术对比表**: 自动生成两者的对比数据（如透明通道支持、是否支持动画、有损/无损压缩算法、典型文件体积比）。
3. **真实场景 FAQ 动态插值**: 针对特定格式的专属问答（如针对 HEIC 解答“为什么 Windows 默认打不开 HEIC 文件”）。
4. **格式专属 How-To 说明**: 具体展示该格式如何导出与使用。
5. **网状交叉内链**: 底部展示“Related Conversions”（相关转换列表），保证爬虫能够在页面间平滑遍历，杜绝孤岛页面。

## 三、 放量节奏与风控时间表

- **第 1 个月（冷启动种子期）**: 上线 20~50 个检索量最高的顶级参数页。监控 GSC 中“已编入索引”与“已抓取”的比例。
- **第 2 个月（小步扩张期）**: 当种子页索引率超过 70% 且产生展示，逐步扩充至 200~500 个次级页面。
- **第 3 个月以上（全面矩阵期）**: 根据 GSC 搜索查询词反向发现的新增搜索习惯，批量补充剩余页面。
