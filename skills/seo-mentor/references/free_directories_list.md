# 出海站长冷启动高权重外链与免费提交目录清单

基于出海实战方法论：新站上线前两周，必须通过优质免费目录、开源社区与垂直平台引入第一批真实搜索引擎爬虫与种子用户。

## 一、 AI 与工具导航站（免费提交流程）

1. **There's An AI For That (TAAFT)**: 全球最大 AI 工具目录之一，提供免费提交入口。
2. **Toolify.ai**: 国内站长做出海的知名 AI 导航站，收录快，有可观展示量。
3. **Futurepedia.io**: 欧美主流 AI 工具目录，审核较为严格，需提供清晰的使用场景。
4. **Dang.ai**: 独立开发者友好的 AI 工具集合站。
5. **TopAI.tools**: 免费提交，自动化收录速度快。
6. **AIcyclopedia**: 收录 AI 相关的各类工具与资源。
7. **AllThatAI**: 免费收录新出的工具类应用。
8. **FutureTools.io**: Matt Wolfe 运营的 AI 工具站，可提交新工具申请收录。

## 二、 综合软件与替代品目录（高 DA 权威外链）

1. **Product Hunt (Upcoming & Launch)**: 必须准备的重大发布平台，附带高权重 dofollow/nofollow 品牌信号。
2. **BetaList**: 适合产品刚上线或公测期的展示。
3. **AlternativeTo**: 极高权重！将你的工具关联到老牌竞品（如关联为 "Free Alternative to Squoosh / TinyPNG"）。
4. **SaaSHub**: 软件替代方案与工具评测平台，免费收录。
5. **SourceForge / Slant / StackShare**: 开发者常用工具比较平台。

## 三、 开发者社区与开源平台（引流与牵引蜘蛛）

1. **GitHub README 链接**:
   - 开源一个轻量版本的前端组件、WebAssembly 核心代码或 API SDK。
   - 在 README 顶部与 About 侧边栏填入官网独立域名链接。GitHub 仓库是 Google 爬虫最常驻扎的高信任度源头。
2. **Reddit 垂直圈子（Showcase 模式）**:
   - `r/SideProject`: 最包容独立开发者的社区，发帖分享制作心路历程与技术实现。
   - `r/WebDev` & `r/Frontend`: 分享纯客户端 WASM / Canvas 的技术挑战与优化经验。
   - `r/InternetIsBeautiful`: 如果工具具有趣味性（如 Pixel Art 生成器），极易产生爆款流量。
3. **Hacker News (Show HN)**: 强调纯客户端本地运行、无后端数据保留、完全隐私保护，极契合 HN 极客胃口。
4. **Dev.to / Hashnode / Medium**: 发布 1 篇深度技术实战教程（如《How to build an offline image compressor in 100 lines of code》），正文中自然锚定主站。

## 四、 浏览器插件商店（双飞轮矩阵）

1. **Chrome Web Store**: 搜索权重极高，扩展详情页可直接放置官网外链。
2. **Microsoft Edge Add-ons**: 审核相对容易，流量稳定。
3. **Mozilla Add-ons (Firefox)**: 欧美技术人群与隐私注重者常用。
